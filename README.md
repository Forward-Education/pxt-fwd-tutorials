# pxt-fwd-tutorials

A central home for MakeCode tutorials that are authored by Forward Education. Tutorials are grouped by company, then by kit.

## How to Use

This extension is not mean to be included in a MakeCode project. Instead, it's used to launch tutorials via links.

For example, here is a path to a tutorial file found in this repo (at the time of writing).
fwd/climate-action/curriculum/treeseeder.md

The launch link for this tutorial uses that filepath.
https://makecode.microbit.org/#tutorial:github:forward-education/pxt-fwd-tutorials/fwd/climate-action/curriculum/treeseeder

If you would like to open a tutorial in this extension, then use the above formula to build the link and launch it.
